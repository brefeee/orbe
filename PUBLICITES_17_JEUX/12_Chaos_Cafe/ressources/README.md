# Chaos Café : ressources

Tout est généré par le code du dossier projet/ : aucune ressource externe. Polices sous licence libre OFL (voir _moteur/fonts/licences).

## Palette (projet/ad.js, ligne 10)
rouge `#e8503a` ; crème `#fff3dc` ; turquoise `#1fb6a6` ; soleil `#ffc23c` ; bois `#b9764a` ; sombre `#3a2318` ; vert `#6fd44f` ; violet `#8f5be0` ; orange `#ff8a2b` ; bleu `#3b9bff` ; rose `#ff7eb0`.
Compléments : cafés montrés (mur / soubassement) `#ffd49a` / `#1fb6a6`, `#ffc2d6` / `#8f5be0`, `#a9ead9` / `#e8503a` ; avertissement `#ffd400` sur `#1b1b22` ; fond `#3a2318` à `#7a4f2b`.

## Polices
Titan (titres) et Inter (textes secondaires, interface).

## Musique
Style `frantic`, 152 bpm (1 mesure = 1,579 s), graine 12 ; sections : build (0 s), drop (3,2 s), break (15,8 s, imprévu), build (17,4 s), drop (20,5 s, robot), drop2 (23,7 s, fête). Synthétisée par _moteur/audio.py.

## Bruitages utilisés (repères `cue`)
whoosh, swish, impact, boom, pop, coin, ding, bell, tick, zap, boing, tap, riser, sweepdown, chime, win, crowd, roll, powerup.

## Modèles 3D créés par le code
- Café : sols en damier (3 variantes), murs, soubassement, tables avec nappe, tasses fumantes, cloches de service, plateaux.
- Les 5 monstres : gelée verte à un œil, boule de poils violette, grand cyclope orange à antennes, gros bleu à trois yeux sur tiges, petite rose volante à pois (yeux, bouches et bras animés).
- Serveurs en blocs du moteur (4), avec plateau.
- Robot assistant.
- Cuisinière avec feu (flammes) et extincteur avec jet.
- Éléments 2D dessinés par le code : bulles de commande (tasse, cœur, cloche) avec barre de patience, pièces, cœurs, panneau d'avertissement, interface de niveau et de pièces.
