# Ressources : SIMULATOR DE SALLE DE MUSCULATION (GYM)

**Palette** (ad.js l.14, l.16, l.18)
- Fond : `#12141b` nuit, `#2a2f3d` ardoise
- Accents : `#b6ff2e` vert citron, `#ff6a1a` orange, `#ffd60a` jaune, `#ff3b4e` rouge, `#39d5ff` cyan, `#c04dff` violet, `#ffffff` blanc
- Qualités des machines : `#9a5630` rouillé, `#9aa3ad` basique, `#5d7fa8` acier, `#e3e8f0` argent, `#ffc21a` or, `#9ff0e4` platine, `#3fd0ff` diamant, `#c04dff` mythique
- Corps : `#b6ff2e`, `#ff6a1a`, `#39d5ff`, `#ff4fa3`, `#ffd60a`

**Polices** : Anton (titres et compteurs), Inter (libellés).

**Musique** : style `workout`, 128 bpm (mesure = 1,875 s). Sections : build, drop, break, drop2, drop ; arrêt court juste avant le clic du rebirth.

**Bruitages** (49 repères `cue`) : whoosh, thud, slide, riser, boom, powerup, impact, pop, ding, swish, bell, coin, tick, chime, zap, win, heartbeat, click, crowd, boing, sweepdown.

**Modèles 3D créés par le code** : salle de sport (sol, murs, enseigne « SALLE DE MUSCU », porte « ENTRÉE »), tapis de course, machine à poulie (lat), barre avec disques, haltères, kettlebell, athlète en blocs (taille de muscles réglable), clients, étiquette de machine, podium avec 3 auras (flammes, cristaux, étoiles), 12 salles d'un serveur avec leurs joueurs, effets d'éclair et de confettis.

Tout est généré par le code du dossier projet/ : aucune ressource externe. Polices sous licence libre OFL (voir _moteur/fonts/licences).
