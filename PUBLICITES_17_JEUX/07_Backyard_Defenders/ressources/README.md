# Backyard Defenders : ressources

Tout est généré par le code du dossier projet/ : aucune ressource externe. Polices sous licence libre OFL (voir _moteur/fonts/licences).

## Palette (projet/ad.js, ligne 14)
herbe `#69c24c` / `#78d05a` ; chemin `#e6c88e`, bord `#b98f55` ; rouge `#ff4d4d` ; bleu `#2f8cff` ; jaune `#ffd23f` ; orange `#ff8a2a` ; vert `#3ccf6e` ; violet `#7b3fe4` ; acier `#c9d2df` ; sombre `#1c1c26` ; bois `#c98f4e` ; blanc `#ffffff`.
Compléments : dégradé de titre `#fff27a` à `#ff9d2e`, contour `#3a1404` / `#14401f`, fond du boss `#4a2a8a`, `#ff9d6b`, `#ffd9a0`, ciel `#59b7ff` / `#c9ecff`, insectes `#f23838` (coccinelle), `#9a4f2a` (fourmi), `#17b7a5` (scarabée), `#5fc02f` / `#9be33f` (chenille), or `#ffcf3a`.

## Polices
Luckiest (titres, textes d'action) et Inter (écran final, textes secondaires).

## Musique
Style `toybox`, 126 bpm (1 mesure = 1,905 s), graine 11 ; sections : build, drop (3,8 s), break (11,4 s), drop (15,2 s), drop2 (22,9 s, boss), drop (28,6 s, écran final). Synthétisée par _moteur/audio.py.

## Bruitages utilisés (repères `cue`)
whoosh, swish, impact, boom, pop, coin, ding, click, tick, laser, zap, boing, splash, thud, slide, riser, chime, win, crowd, horn, powerup.

## Modèles 3D créés par le code
- Décor : pelouse tondue en bandes, chemin sinueux avec cailloux, terrier d'où sortent les insectes, clôture blanche, fleurs, buissons, arbres, champignons, piscine gonflable avec canard, bac à sable, nappe de pique-nique, arrosoir avec tuyau, terrasse avec coffre à jouets, zones de couleur des 4 joueurs, cercle de portée.
- Insectes : coccinelle, fourmi, scarabée, chenille (5 segments), la Reine Scarabée (carapace violette, couronne dorée).
- Jouets : pistolet à eau, robot, ballon, avion (socle commun) et leurs projectiles (gouttes, éclairs, balles).
- Personnages en blocs du moteur (4 joueurs).
- Éléments 2D dessinés par le code : interface de vague et de pièces, cartes d'amélioration, barre de boss.
