# Bumper Ball Arena : ressources de la publicité

## Palette (relevée dans projet/ad.js)
- Marine `#0a1030`, rouge `#ff3b3b`, or `#ffd23f`, bleu `#2f7bff`, orange `#ff8a1f`, cyan `#22d3ee`, blanc `#ffffff`
- 12 couleurs de boules : `#ff3b3b`, `#35d07f`, `#ffd23f`, `#a05cff`, `#22d3ee`, `#ff6fb5`, `#ff8a1f`, `#3b82f6`, `#b6f03c`, `#f1f5f9`, `#e94bd8`, `#14b8a6`
- Ciels : Île (`#1565d8`, `#58b8ff`, `#d9f3ff`), Lac gelé (`#0b2a6b`, `#3f8be0`, `#d6f3ff`), Parc à ressorts (`#3b1a8f`, `#b04cd8`, `#ffb37a`), mêlée (`#101a52`, `#e0527d`, `#ffc46b`), écran final (`#2a1378`, `#a044cf`, `#ff9f6b`)
- Bandeaux : fond HUD `rgba(10,16,48,.86)`, vert victoire `#16a34a`, violet `#7c3aed`

## Polices
- Titres et textes : Anton
- Textes secondaires : Inter

## Musique
- Style « arena », 100 bpm (une mesure = 2,4 s)
- Sections : build, drop, build, drop2, outro

## Bruitages utilisés
whoosh, roll, sweepdown, crowd, whistle, tick, crunch, slide, win, horn, boing, chime, swish, powerup, zap, riser, pop, boom, ding, impact

## Modèles 3D créés par le code
- Boule de joueur (coque translucide, cerceaux qui montrent le roulement, personnage en blocs à l'intérieur), 12 boules plus 2 équipes de 3 (bleue, orange)
- Arène 1 : Île qui rétrécit (3 anneaux qui tombent)
- Arène 2 : Lac gelé (patinoire flottante, 2 buts), gros ballon
- Arène 3 : Parc à ressorts (trampolines, zone dorée avec faisceau)
- Bonus : aimant, super saut, géant (objets à ramasser), aimant flottant, anneaux d'attraction, couronne
- Nuages sous les arènes, halos d'impact, étincelles
- Affichages 2D : nom d'arène, chrono, compteur, scores d'équipe, barre de zone, titres de modes

Tout est généré par le code du dossier projet/ : aucune ressource externe. Polices sous licence libre OFL (voir _moteur/fonts/licences).
