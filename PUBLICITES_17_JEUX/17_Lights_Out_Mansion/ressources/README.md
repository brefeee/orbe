# Lights Out Mansion : ressources de la publicité

## Palette (relevée dans projet/ad.js)
- Bois `#3a2748`, bois clair `#5b3d70`, sombre `#231640`, or `#ffd23c`, lampe `#ffe9a0`, cyan fantôme `#7dffe0`, violet `#a78bff`, tapis `#9c2f6b`, orange `#ff8a2a`
- Murs : violet `#5646a6` / `#4a3b92`, bleu `#3a6f96` / `#326188`, rose `#7a4a9c` / `#6c3f8e`
- Fantômes : Feu Follet `#c4fff0` (lueur `#19d9a8`), Grognon `#ebe4ff` (lueur `#6b50d6`)
- Pièces du plan : 12 teintes de `#8a6ad8` à `#d07a5a` ; piles `#2ecc71` ; fenêtres `#ffd76a` et `#ffb347`
- Éclairage : soleil `#b9c6ff`, lueur fantôme `#7dffe0`, lumière chaude `#ffc070`

## Polices
- Titres : Creepster
- Textes secondaires : Inter

## Musique
- Style « spooky », 96 bpm (une mesure = 2,5 s)
- Sections : intro, build, break, drop, break, build, drop2

## Bruitages utilisés
ghost, whoosh, tap, swish, boing, click, impact, sweepdown, tick, powerup, slide, ding, coin, chime, zap, boom, thud, heartbeat, pop, riser, win, bell

## Modèles 3D créés par le code
- Explorateurs en blocs (moteur) avec lampe de poche et faisceau lumineux (4 personnages : orange, turquoise, rose, jaune)
- Fantômes : le Grognon (corps, frange, bras, chapeau, visage dessiné) et le Feu Follet (flamme lumineuse avec traînée)
- Les 5 objets : clé, livre, bougeoir, horloge, ours en peluche ; pile de lampe
- Décor 1 : couloir (portes, tableaux de fantômes, appliques à bougie, fenêtres de lune, tables, toiles d'araignée)
- Décor 2 : plan du manoir de 12 pièces avec liaisons lumineuses
- Décor 3 : bibliothèque (étagères, meubles de présentation, appliques)
- Décor 4 : grand hall (escalier, colonnes, lustre, fauteuils, fenêtre géante)
- Décor 5 : chambre (lit à baldaquin, commode, armoire avec yeux)
- Décor 6 : extérieur du manoir (façade en pierre, tour, tourelles, fenêtres éclairées, porte d'entrée, lanternes, arbres morts, citrouilles)
- Affichages 2D : batterie, compteur d'objets, étiquettes, barre de réanimation

Tout est généré par le code du dossier projet/ : aucune ressource externe. Polices sous licence libre OFL (voir _moteur/fonts/licences).
