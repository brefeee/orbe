# Ressources : RAFT CREW

**Palette** (ad.js l.12-18)
- Océan et ciel : `#17a6c9` mer, `#0b76a8` mer profonde, `#7fe3ee` mer claire, `#3fb4f0` ciel, `#d6f5ff` ciel bas
- Bois : `#c98d4e`, `#b97c3f`, `#d9a05f`, `#a86f36`, `#cf9655` ; foncé `#7a4a22`
- Décor : `#f6d98c` sable, `#35b863` feuilles, `#ecdcae` corde
- Accents : `#ff5a3c` corail, `#ffd23f` soleil, `#0d3b53` marine
- Requin : `#5f7488` corps, `#eef3f6` ventre
- 3 ambiances de mer : jour (`#0c7fb4` / `#19a9cc` / `#8be9f0`), orage, coucher de soleil

**Polices** : Lilita (titres), Inter (compteurs).

**Musique** : style `tropical`, 104 bpm (mesure = 2,31 s). Sections : build, drop, break, drop2, build, drop2.

**Bruitages** (43 repères `cue`) : splash, crunch, heartbeat, impact, boom, boing, whoosh, swish, pop, chime, ding, coin, powerup, riser, slide, sweepdown, tick, win.

**Modèles 3D créés par le code** : océan animé (vagues recalculées à chaque image), radeau en grille de cases de planches et traverses, crochet et corde, tonneaux, caisses, établi, planches et feuilles flottantes, éclaboussures, personnages en blocs (héros, apeuré, surpris, 3 amis) avec marteau, requin, palmiers, 2 îles, nuages.

Tout est généré par le code du dossier projet/ : aucune ressource externe. Polices sous licence libre OFL (voir _moteur/fonts/licences).
