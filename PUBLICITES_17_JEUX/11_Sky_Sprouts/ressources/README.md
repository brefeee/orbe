# Sky Sprouts : ressources

Tout est généré par le code du dossier projet/ : aucune ressource externe. Polices sous licence libre OFL (voir _moteur/fonts/licences).

## Palette (projet/ad.js, ligne 13)
rose `#ff6fb5` ; rose pâle `#ffc4e4` ; lavande `#b79cff` ; violet `#6a4be0` ; encre `#3a2a78` ; ciel `#8fd3ff` ; menthe `#22b8a0` ; herbe `#a6e89a` ; or `#ffd84a` ; crème `#fff6e0` ; orange `#ff9f2e`.
Compléments : rocher des îles `#c3a3e6` / `#a184d1`, soleil `#fff3e0`, ciel `#efe6ff`, sol `#d9b3e0`, fontaine `#c9b6ff` / `#b79cff`, poussière `#ffe27a`.

## Polices
Baloo (titres) et Inter (textes secondaires).

## Musique
Style `dreamy`, 100 bpm (1 mesure = 2,4 s) ; sections : intro (0 s), build (2,4 s), drop (7,2 s), break (15,6 s, mutations), build (19,2 s, œuf), drop2 (21,6 s, éclosion), break (28,8 s, écran final). Synthétisée par _moteur/audio.py.

## Bruitages utilisés (repères `cue`)
whoosh, swish, impact, boom, pop, coin, ding, bell, tick, boing, bubble, thud, tap, slide, riser, sweepdown, chime, win, crunch, glass, powerup.

## Modèles 3D créés par le code
- Îles flottantes pastel (herbe, rocher, fleurs) et décor de ciel lointain avec arbres.
- Graine d'étoile (étoile dorée à cœur lumineux).
- Sprouts (créatures rondes) : feuille, lapin, nuage, étoile, chat, champignon, lune, dragon (version Légendaire) ; trois versions mutantes (dorée, arc-en-ciel, cristal).
- Fontaine d'étoiles (socle, cristal violet, bassin de poussière dorée), parcelles de plantation.
- Décorations de l'île (lampe, fleurs, etc.), scène de l'œuf (nid, œuf tacheté).
- Personnages en blocs du moteur (le joueur et son ami).
- Éléments 2D dessinés par le code : interface « GRAINES » et « POUSSIÈRE », étoiles, éclats, rayons de lumière.
