# Tumble Tower : ressources

Tout est généré par le code du dossier projet/ : aucune ressource externe. Polices sous licence libre OFL (voir _moteur/fonts/licences).

## Palette (projet/ad.js, ligne 14)
rose `#ff3d81` ; jaune `#ffc21f` ; cyan `#2ee6ff` ; citron vert `#6dfc4b` ; violet `#a66bff` ; orange `#ff7a2e` ; marine `#141a3c` et `#222a5c` ; glace `#bff3ff` ; vert `#2bff8a` ; blanc `#ffffff`.
Compléments : bandeaux d'étages (rose, jaune, cyan, citron vert, violet, orange, un changement de couleur tous les 3 étages), interface `#10163a`, vert de sauvegarde `#0f9d58`, bleu glace `#1d8fe0`, fond de tour `#161d45` / `#0c1130`, herbe `#5fc76a`.

## Polices
RubikMono (titres, numéros d'étage) et Inter (textes secondaires).

## Musique
Style `dnb`, 172 bpm (1 mesure = 1,395 s), tonique MIDI 45, graine 8 ; sections : drop (0 s), build (2,8 s), drop (7,0 s), break (19,5 s, chute), drop2 (23,7 s, montée finale). Synthétisée par _moteur/audio.py.

## Bruitages utilisés (repères `cue`)
whoosh, swish, impact, boom, pop, coin, ding, tick, boing, thud, tap, slide, riser, sweepdown, chime, win, fail, crowd, whistle, glass, roll, powerup.

## Modèles 3D créés par le code
- Tour de 36 étages : cœur sombre à fenêtres éclairées, liseré néon par étage, plateformes principales et marches, numéros d'étage.
- Points de sauvegarde (anneau lumineux, drapeau vert) et point vedette de l'étage 18 (faisceau, halo).
- Obstacles : barre tournante (étage 13), disque tournant à flèches, plateforme de glace translucide (étage 15), obstacle rebondissant, trois plateformes violettes qui disparaissent.
- Décor : île de départ, arbres, nuages.
- Héros en blocs (deux visages, content et effrayé) avec traînée lumineuse ; maquette de la « tour du jour » avec 4 spectateurs en blocs.
- Éléments 2D dessinés par le code : calendrier, tableau de classement, interface d'étage.
